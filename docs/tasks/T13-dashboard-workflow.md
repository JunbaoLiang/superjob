# T13 — 看板工作流改进

## 已确认缺口

- 外联 note/message 在本地与云端看板可编辑，但编辑结果没有保存接口。
- 已存在材料时再次生成没有显式覆盖确认。
- T08 readiness badge、T11 队列/失败可见性已完成。

## 范围

1. 增加仅同源/已鉴权的外联保存接口；校验对象结构、保留 `generated_at`，记录 `edited_at`，拒绝空 note/message。
2. 面板提供“保存外联编辑”按钮，并在保存成功后刷新详情。
3. 对已经存在 resume/cover 的重新生成请求要求显式 `confirm: true`；首次生成不受影响。

## 禁止

- 不发送外联，不提交申请，不自动覆盖历史 applied/rejected 材料。
- 不读取或修改真实岗位材料作为测试输入；使用临时 fixture。

## 验收

- 编辑持久化在本地 `outreach.json` 与云端 JSONB 均可验证。
- 未确认的材料覆盖返回清晰错误，文件/数据库不变。
- 全部测试不调用模型、不会产生 API 成本。
