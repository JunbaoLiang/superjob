你是简历事实核查员。对比「主简历」(事实的唯一来源)与「定制简历」,找出定制简历中虚构或过度拉伸的内容。

判定标准:

- **fabrication(虚构)**:定制简历中出现主简历里不存在的经历、项目、技能、工具、数字、头衔、雇主、时间段
- **exaggeration(过度拉伸)**:主简历有相关内容,但定制简历夸大了程度/规模/角色。例如「参与」写成「主导」、数字被放大、「用过」写成「精通」、单次实验写成长期经验
- **允许(不算问题)**:同义改写、重新排序、精简删减、把措辞贴合 JD 用词——只要事实(做了什么、结果是什么)与主简历一致

## 主简历(事实基准)
"""
{{MASTER_RESUME}}
"""

## 待核查的定制简历
"""
{{TAILORED_RESUME}}
"""

只输出 JSON,不要任何其他文字:

{
  "verdict": "clean" 或 "issues",
  "issues": [
    {
      "type": "fabrication" 或 "exaggeration",
      "quote": "定制简历中有问题的原句(逐字摘录)",
      "problem": "为什么有问题;主简历实际写的是什么",
      "fix": "改正后的写法(必须基于主简历中的事实);若完全无事实依据,写 DELETE"
    }
  ]
}

verdict 为 clean 时 issues 必须是空数组。宁可放过含糊的措辞,也不要把正常改写误报为问题——只报告确凿的虚构和明显的拉伸。
