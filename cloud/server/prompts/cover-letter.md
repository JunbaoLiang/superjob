**严格按下面的行文,每一块之间空一行。抬头/日期/称呼/落款各自独立成行,不要合并。正文每段写成单独一行(段内不要手动换行)。**

- **[JD 的第三个要求或加分项]** — [对应的具体证据,一句话。]

## 要点

- 中间用 3 条 bullet,每条形如「岗位要求 → 我的对应证据」,让匹配关系一目了然;bullet 之外不要再堆砌大段罗列

- 全文 250–350 词,控制在一页内
- 抬头里的姓名/城市/邮箱/电话从定制简历顶部照抄
